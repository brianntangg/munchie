# Munchie

Munchie is a social platform designed for Vanderbilt students to share real-time photos of campus dining during breakfast, lunch, and dinner. By showing what students and their friends are eating across campus, Munchie helps users discover current food options, rate their dining experiences, and decide where to eat. The platform makes campus dining more social by helping students stay connected and enjoy meals together.

## Features

Planned features include:

- Vanderbilt student authentication
- Real-time dining feed
- Food photo uploads
- Breakfast, lunch, and dinner posting windows
- Dining hall and food ratings
- Likes and comments
- Friends/following system
- Manual and automatic feed refresh
- Vanderbilt dining information integration

## Tech Stack

- **Frontend:** React Native
- **Development Platform:** Expo
- **Language:** TypeScript
- **Backend:** Supabase
- **Database:** PostgreSQL
- **Authentication:** Supabase Auth with Vanderbilt email verification
- **Image Storage:** Supabase Storage
- **Version Control:** Git and GitHub

## Project Structure

The project will use a React Native and Expo frontend connected to Supabase for backend services. Supabase will handle authentication, PostgreSQL data storage, and image storage for user-uploaded food photos.

## Target Users

Munchie is initially designed specifically for Vanderbilt University students who use campus dining and want a more social, real-time way to discover food options.

## Sprint 2 MVP

The core local MVP includes verified Vanderbilt email sign-in, display names, meal photo posting, and a shared dining feed. See [Sprint 2 setup and acceptance checks](docs/sprint-2.md).
